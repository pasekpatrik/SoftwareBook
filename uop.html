Organizace a bezpečnost

  • Docházka je povinná; hodnocení vychází ze závěrečného testu.
  • Přístup na školní server k332 je přes osobní účet; SSH může vyžadovat školní VPN nebo port uvedený vyučujícím.

2. Shell a soubory

Příkazy se skládají z názvu, voleb a argumentů. Nápovědu hledej v manuálových stránkách.

Základní příkazy

PříkazCo dělá a příklad
pwdVypíše aktuální adresář.
ls -lahVypíše obsah včetně skrytých souborů, detailů a čitelných velikostí.
cd cestaZmění adresář; cd .. o úroveň výš, cd ~ domů, cd - zpět.
mkdir -p cestaVytvoří adresář včetně chybějících nadřazených adresářů.
touch souborVytvoří prázdný soubor nebo aktualizuje čas změny.
cp -r zdroj cílZkopíruje soubor nebo adresář.
mv zdroj cílPřesune nebo přejmenuje soubor.
rm souborSmaže soubor; rm -r adresář maže rekurzivně. Obvykle není k dispozici undelete.
cat souborVypíše obsah; less soubor umožní procházení, ukončení klávesou q.
file cestaRozpozná typ souboru.
find cesta -name '*.log'Vyhledá soubory podle názvu.
grep -in 'text' souborVyhledá řádky; -i ignoruje velikost písmen, -n vypíše čísla řádků.
man příkazOtevře manuál; příkaz --help zobrazí stručnou nápovědu.

Užitečné textové nástroje

head a tail zobrazí začátek a konec souboru; tail -f sleduje přibývající řádky. sort řadí, uniq odstraňuje sousední duplicity, wc počítá řádky/slova/znaky a diff porovnává soubory.

grep -i 'error' app.log | sort | uniq
find . -type f -name '*.conf'
cat /etc/passwd | grep '^root:'
Roura | předá standardní výstup jednoho programu na standardní vstup dalšího. Často je přehlednější vynechat zbytečné cat: grep 'text' soubor | sort.

3. Uživatelé a oprávnění

Práva souboru jsou oddělená pro vlastníka, skupinu a ostatní.

Práva a účty

PříkazPoužití
whoamiZobrazí aktuálního uživatele.
id uživatelZobrazí UID, primární skupinu a další skupiny.
groupsVypíše skupiny aktuálního uživatele.
chmod u+x skript.shPřidá vlastníkovi právo spouštění.
chmod 640 souborČíselně nastaví práva: vlastník čtení/zápis, skupina čtení, ostatní bez práv.
chown uživatel:skupina souborZmění vlastníka a skupinu; obvykle vyžaduje sudo.
sudo příkazSpustí jeden příkaz s oprávněními správce.
passwdZmění heslo aktuálního účtu.

r = čtení (4), w = zápis (2), x = spuštění/průchod (1). Hodnota 755 znamená vlastník rwx, skupina a ostatní r-x.

Přístup k adresáři vyžaduje právo x. Uživatelé / skupiny se spravují podle distribuce, například příkazy adduser, usermod a groupadd; prováděj je jen s potřebným oprávněním.

4. Procesy, shell a skripty

Shell spojuje příkazy, přesměrování a řízení běžících úloh.

Procesy a úlohy

Příkaz / klávesaVýznam
ps auxMomentální přehled procesů; top zobrazuje jejich stav průběžně.
pgrep názevNajde PID podle názvu procesu.
kill PIDPošle procesu standardně SIGTERM (zdvořilý požadavek na ukončení).
kill -9 PIDPošle SIGKILL; proces ho nemůže zachytit. Použij až jako poslední možnost.
jobsVypíše úlohy aktuálního shellu.
příkaz &Spustí příkaz na pozadí.
fg / bgVrátí úlohu do popředí / obnoví ji na pozadí.
Ctrl+Z / Ctrl+CPozastaví úlohu / pošle přerušení úloze v popředí.
echo $?Vypíše návratový kód posledního příkazu; nula obvykle znamená úspěch.

Vstup, výstup a řetězení

program > vystup.txt       # přepíše výstupní soubor
program >> vystup.txt      # připojí výstup na konec
program < vstup.txt        # načte vstup ze souboru
program >out.txt 2>err.txt # oddělí běžný výstup a chyby
program >/dev/null 2>&1   # zahodí oba výstupy
prikaz1 | prikaz2           # výstup prvního předá druhému
prikaz | tee kopie.log     # zobrazí výstup a zároveň uloží kopii

&& spustí další příkaz jen při úspěchu předchozího; || při jeho neúspěchu.

Proměnné a skripty Bash

#!/usr/bin/env bash
printf 'Uživatel: %s\n' "$USER"
for soubor in *.log; do
  [ -e "$soubor" ] || continue
  echo "$soubor"
done

Wildcardy: * odpovídá libovolnému počtu znaků, ? právě jednomu znaku a [abc] jednomu vyjmenovanému znaku. Skript spusť například pomocí chmod u+x skript.sh a ./skript.sh. Vždy cituj proměnné obsahující cesty: "$soubor".

Vzdálený přístup a terminál

ssh uzivatel@server
ssh -p 8822 uzivatel@server
ssh-keygen -R server

SSH šifruje spojení. Změněný otisk serveru ověř jiným důvěryhodným kanálem, než starý záznam odstraníš. Pro odpojitelnou terminálovou relaci se používá tmux nebo screen.

5. Disky a souborové systémy

Od zařízení a oddílů přes RAID/LVM až po připojený adresář.

Kontrola disků a místa

PříkazÚčel
lsblk -fVypíše zařízení, oddíly, typy FS, štítky a UUID.
blkidZobrazí UUID a další vlastnosti blokových zařízení.
df -hVolné místo připojených souborových systémů.
du -sh cestaSouhrnná velikost adresáře.
mountZobrazí připojené souborové systémy.
findmntPřehledná hierarchie připojených souborových systémů.

Oddíly, souborové systémy a připojení

  • GPT je moderní tabulka oddílů, která nahrazuje omezení MBR. Oddíly upravuj nástroji jako fdisk, parted nebo grafickým GParted.
  • Souborový systém vytváří například mkfs.ext4 /dev/oddil; kontrola/oprava se provádí nástrojem fsck, obvykle na odpojeném souborovém systému.
  • Připojení: sudo mount /dev/oddil /mnt/data; odpojení: sudo umount /mnt/data.
  • Trvalá konfigurace se zapisuje do /etc/fstab. Používej UUID nebo LABEL, protože názvy typu /dev/sda se mohou změnit.
# Příklad fstab: UUID zjisti příkazem lsblk -f nebo blkid
UUID=xxxx-xxxx  /mnt/data  ext4  defaults  0  2

RAID a LVM

RAID kombinuje více zařízení pro výkon nebo odolnost vůči výpadku disku. RAID není záloha. LVM skládá PV (physical volume) do VG (volume group) a z nich vytváří LV (logical volume), které lze pružně měnit.

# Příklady pouze pro testovací virtuální disky
sudo mdadm --create /dev/md0 --level=1 --raid-devices=2 /dev/sdb /dev/sdc
sudo pvcreate /dev/sdb1
sudo vgcreate data_vg /dev/sdb1
sudo lvcreate -L 10G -n data_lv data_vg

Odkazy, swap a síťová úložiště

ln puvodni.txt hardlink.txt
ln -s /cesta/k/cili symlink
swapon --show
sudo mkswap /swapfile && sudo swapon /swapfile
sshfs uzivatel@server:/data ~/remote-data

Hard link odkazuje na stejná data na témže souborovém systému; symbolický odkaz uchovává cestu a může mířit i na adresář či jiný souborový systém. Síťové alternativy zahrnují NFS, SMB/Samba a SSHFS.

Pozor, destruktivní
mkfs, mdadm --create, pvcreate a zápisy do /etc/fstab mohou zničit data nebo zabránit startu systému. Zkoušej je pouze ve virtuálním prostředí s ověřenými zařízeními a zálohou.

6. Start systému a systemd

Bootloader zavede kernel; PID 1 dokončí start uživatelského prostoru a spravuje služby.

Od bootu ke službě

Zjednodušeně: firmware (BIOS/UEFI) → bootloader (například GRUB) → kernel a initramfs → PID 1 → služby a přihlášení uživatelů.

SysVinit používá mimo jiné runlevely a skripty v /etc/init.d. V současných distribucích je běžný systemd; ekvivalentem cílového stavu je target. Starší příkazy init/telinit jsou závislé na distribuci.

systemctl

systemctl status ssh
sudo systemctl start ssh
sudo systemctl stop ssh
sudo systemctl restart ssh
sudo systemctl enable --now ssh
sudo systemctl disable ssh
systemctl is-active ssh
systemctl list-units --type=service
systemctl list-unit-files --type=service

start/stop mění stav teď; enable/disable mění automatické spouštění při startu. --now současně službu spustí nebo zastaví.

Logy, cíle a konfigurace

journalctl -b                 # logy aktuálního startu
journalctl -u ssh -f          # průběžné logy služby
journalctl -p err..alert      # chyby a závažnější události
systemctl get-default         # výchozí target
systemctl list-dependencies  # závislosti

Vlastní jednotky se obvykle ukládají do /etc/systemd/system/. Po změně souboru jednotky načti konfiguraci přes sudo systemctl daemon-reload.

7. Instalace softwaru

Správce balíčků řeší instalaci, závislosti, aktualizace i odstranění.

APT a dpkg (Debian/Ubuntu)

sudo apt update
sudo apt upgrade
sudo apt install balicek
sudo apt remove balicek
apt search vyraz
dpkg -l | grep balicek
dpkg -L balicek
dpkg -S /cesta/k/souboru

apt update obnovuje seznamy balíčků, neinstaluje aktualizace. apt upgrade aktualizuje nainstalované balíčky. dpkg pracuje s lokální databází balíčků; závislosti za něj řeší APT.

Další způsoby instalace

  • Zdrojový kód: nejprve čti README/INSTALL a ověř závislosti; častý postup je ./configure, make, instalace podle dokumentace. Neinstaluj bez rozmyslu jako root.
  • Snap: snap list, snap find název, sudo snap install balicek, sudo snap remove balicek.
  • Flatpak: flatpak search název, flatpak install flathub ID, flatpak list, flatpak update.
Pro běžnou instalaci preferuj důvěryhodný repozitář distribuce. Balíčky z náhodných webů nebo příkazy stažené přímo do shellu mohou obejít aktualizace a bezpečnostní kontrolu.

8. Sítě a diagnostika

Moderní nástroj pro konfiguraci rozhraní a tras je příkaz ip.

Rozhraní, adresy, trasy a DNS

PříkazÚčel / příklad
ip addrVypíše IP adresy síťových rozhraní.
ip linkVypíše stav rozhraní; sudo ip link set eth0 up rozhraní zapne.
ip routeZobrazí směrovací tabulku; ip route get 1.1.1.1 ukáže vybranou trasu.
ping -c 4 hostOvěří základní dosažitelnost přes ICMP.
ss -tulpnZobrazí naslouchající TCP/UDP sockety a procesy.
resolvectl statusZobrazí stav DNS resolveru na systémech se systemd-resolved.
tcpdump -i eth0Zachytává síťový provoz; může vyžadovat oprávnění správce.
 
ip addr show
ip route
sudo ip addr add 192.168.10.20/24 dev eth0
sudo ip route add 10.0.0.0/8 via 192.168.10.1

ifconfig, route a netstat jsou starší nástroje; jejich moderní alternativy jsou ip a ss. Konkrétní názvy rozhraní a správu sítě určuje distribuce.

Firewall

Linux používá pro filtrování paketů subsystém netfilter. iptables je stále možné potkat, ale současné systémy často používají nftables nebo nástroje jako UFW.

sudo ufw status
sudo ufw allow 22/tcp
sudo ufw deny 22/tcp
Změna firewallu přes SSH může okamžitě odříznout vzdálený přístup. Před změnou pravidel si připrav možnost lokální obnovy a povol správný port dřív, než nastavíš výchozí blokování.
