Úloha 1: Zabezpečení přepínače

Příkazy a ověření pro Port Security, DHCP Snooping, Dynamic ARP Inspection a IP Source Guard. Jednotlivé příkazy kopíruj do správného zařízení a režimu.

Router a DHCP Port Security DHCP Snooping DAI a Source Guard Obnova
Topologie: router R1 je na portu Fa0/1 switche; PC-vlevo na Fa0/4 a PC-vpravo se podle kroku přepojuje mezi Fa0/6 a Fa0/5. Router používá 192.168.66.254/24, VLAN je 1. Před konfigurací si ověř fyzické zapojení.

3. Router R1: rozhraní a DHCP server

Na routeru nakonfiguruj Fa0/1 a DHCP pool pro síť 192.168.66.0/24.

Konfigurace routeru

enable

Přejde do privilegovaného režimu routeru R1#.

configure terminal

Otevře globální konfigurační režim.

interface FastEthernet 0/1

Vybere port routeru připojený do switche.

ip address 192.168.66.254 255.255.255.0

Nastaví router na adresu 192.168.66.254/24.

no shutdown

Zapne rozhraní Fa0/1.

exit

Vrátí se do globální konfigurace routeru.

ip dhcp excluded-address 192.168.66.254

Vyloučí adresu routeru z DHCP rozsahu.

ip dhcp pool VLAN_1

Vytvoří DHCP pool pro laboratorní síť.

network 192.168.66.0 255.255.255.0

Nastaví síť a masku DHCP poolu.

default-router 192.168.66.254

Předá klientům adresu routeru jako výchozí bránu.

end

Ukončí konfiguraci a vrátí prompt na R1#.

show ip dhcp binding

Ověří přidělené DHCP adresy.

show ip interface brief

Ověří IP adresu a stav rozhraní Fa0/1.

4. Obnovení adres na počítačích

Na obou počítačích obnov DHCP lease přes síťové rozhraní NIC2; v Linuxu ověř adresu a trasu.

Linux: NIC2 (v zadání typicky enp4s0)

ip a

Zobrazí síťová rozhraní a jejich adresy; ověř název NIC2.

sudo dhclient -r enp4s0

Uvolní stávající DHCP lease na NIC2.

sudo dhclient enp4s0

Vyžádá novou adresu z DHCP serveru. Název rozhraní uprav podle výstupu ip a.

ip r

Ověří výchozí trasu a gateway přidělenou DHCP serverem.

Krok 4 můžeš na pracovních stanicích provést také odpojením a opětovným připojením NIC2, jak uvádí zadání.

5–6. Fa0/6: povolená pevná MAC adresa

Povol na portu Fa0/6 pouze MAC 00:01:02:03:04:05 a při porušení pravidla port vypni.

Konfigurace na switchi SW4

enable

Přejde do privilegovaného režimu switche.

configure terminal

Otevře globální konfiguraci.

interface FastEthernet 0/6

Vybere port, na který se v kroku 6 připojí PC-vpravo.

switchport mode access

Nastaví port jako access port.

switchport access vlan 1

Přiřadí port do VLAN 1.

switchport port-security

Zapne Port Security na portu.

switchport port-security maximum 1

Povolí na portu jednu MAC adresu.

switchport port-security mac-address 0001.0203.0405

Ručně povolí MAC adresu 00:01:02:03:04:05 ve formátu Cisco.

switchport port-security violation shutdown

Při jiné MAC adrese přepne port do stavu err-disabled.

end

Ukončí konfiguraci.

show port-security interface FastEthernet 0/6

Ověří nastavení a stav Port Security na Fa0/6.

show interfaces status

Po připojení PC ověří, zda se port kvůli porušení pravidla vypnul.

Po připojení PC-vpravo zkus ping na PC-vlevo. Jestli se skutečná MAC PC-vpravo neshoduje s povolenou adresou, očekávej porušení pravidla a vypnutí Fa0/6.

7. Fa0/5: dynamické učení MAC (sticky)

Přesuň PC-vpravo na Fa0/5. Switch se naučí první MAC adresu a další zařízení odmítne.

Konfigurace a ověření na switchi

configure terminal

Vstoupí do globální konfigurace.

interface FastEthernet 0/5

Vybere port pro PC-vpravo.

switchport mode access

Nastaví port jako access.

switchport access vlan 1

Přiřadí port do VLAN 1.

switchport port-security

Zapne Port Security.

switchport port-security maximum 1

Povolí jedinou naučenou MAC adresu.

switchport port-security mac-address sticky

Dynamicky naučenou MAC uloží jako sticky adresu v běžící konfiguraci.

switchport port-security violation shutdown

Při připojení jiné MAC port vypne.

end

Ukončí konfiguraci.

show port-security interface FastEthernet 0/5

Ověří naučenou MAC, počet porušení a stav portu.

show running-config interface FastEthernet 0/5

Zobrazí konfiguraci portu včetně případné sticky MAC adresy.

8–10. Podvržený DHCP server na PC-vpravo

Odpoj router a na PC-vpravo nastav DHCP server v laboratorním Webminu. Následující nastavení je v grafickém rozhraní, nejde o příkazy Cisco.

Webmin: konfigurace DHCP serveru

  1. Otevři http://127.0.0.1:10000 a přihlas se laboratorním účtem podle pokynů cvičícího.
  2. V konfiguraci DHCP odstraň původní subnet a založ nový subnet s popisem Attacker Subnet.
  3. Nastav Network Address 192.168.66.0, Netmask 255.255.255.0 a Address Range podle zadání. Počáteční adresu uprav podle skutečného rozsahu a adresy PC-vpravo.
  4. V Client Options nastav Default Routers na aktuální IP adresu PC-vpravo.
  5. Vyber rozhraní NIC2 (v zadání enp4s0), ulož změny a DHCP službu aktivuj.
  6. Na PC-vlevo obnov DHCP lease. Potom ověř, že klient dostal adresu z neautorizovaného serveru.
sudo dhclient -r enp4s0

Na PC-vlevo uvolní aktuální lease NIC2 před testem podvrženého serveru.

sudo dhclient enp4s0

Na PC-vlevo požádá o novou adresu; tento test proveď pouze podle kroku 10 zadání.

ip a

Ověří přidělenou adresu na NIC2.

ip r

Ověří, jakou výchozí bránu klient obdržel.

Pozor: Router je v kroku 8 odpojený, takže DHCP Snooping ještě nemůže ověřit autorizovaný server. PC-vlevo obnov adresu přesně podle instrukcí a potom vrať router do topologie.

11–12. DHCP Snooping

Zapni Snooping pro VLAN 1, důvěřuj pouze portu k routeru a omez příchozí DHCP pakety na 50 za sekundu.

Konfigurace na switchi SW4

configure terminal

Otevře globální konfiguraci switche.

ip dhcp snooping

Globálně zapne DHCP Snooping.

no ip dhcp snooping information option

Vypne vkládání Option 82, které může být nekompatibilní s laboratorním DHCP serverem.

ip dhcp snooping vlan 1

Aktivuje DHCP Snooping ve VLAN 1.

interface FastEthernet 0/1

Vybere port switche propojený s R1. Pokud topologie používá jiný port, uprav číslo.

ip dhcp snooping trust

Povolí DHCP odpovědi přicházející z legitimního routeru.

exit

Vrátí se do globální konfigurace switche.

interface FastEthernet 0/4

Vybere nedůvěryhodný klientský port PC-vlevo.

ip dhcp snooping limit rate 50

Omezí DHCP pakety od klienta na 50 za sekundu, aby nezahltil DHCP server.

exit

Vrátí se do globální konfigurace switche.

interface FastEthernet 0/5

Vybere nedůvěryhodný klientský port PC-vpravo.

ip dhcp snooping limit rate 50

Omezí DHCP pakety od PC-vpravo na 50 za sekundu.

end

Ukončí konfiguraci.

show ip dhcp snooping

Ověří aktivní VLAN, stav Snooping a důvěryhodné porty.

show ip dhcp snooping binding

Zobrazí naučené vazby MAC, IP, VLAN a portu.

Důvěryhodný je pouze uplink k routeru. Rate limit je nastavený na klientských access portech Fa0/4 a Fa0/5, kde omezuje DHCP provoz od koncových stanic.

Obnovení a ověření autorizovaného DHCP

Zapoj router zpět, na PC-vlevo obnov lease NIC2 a porovnej přidělenou adresu a čas s DHCP bindingem na routeru.

sudo dhclient -r enp4s0

Uvolní předchozí adresu na PC-vlevo.

sudo dhclient enp4s0

Vyžádá lease znovu; legitimní odpověď má přijít z důvěryhodného portu routeru.

show ip dhcp binding

Na R1 porovná přidělenou IP a čas lease.

show ip dhcp snooping binding

Na SW4 ověří záznam klienta v binding databázi.

13–14. DAI a IP Source Guard

Zapni kontrolu ARP ve VLAN 1, důvěřuj uplinku k routeru a kontrolu zdrojové IP nastav na klientském portu.

Ochrana na switchi SW4

configure terminal

Otevře globální konfiguraci switche.

ip arp inspection vlan 1

Zapne Dynamic ARP Inspection pro VLAN 1; ověř, že DHCP Snooping vytvořil bindingy.

interface FastEthernet 0/1

Vybere uplink switche k routeru.

ip arp inspection trust

Označí uplink jako důvěryhodný pro DAI.

exit

Vrátí se do globální konfigurace.

interface FastEthernet 0/5

Vybere klientský port PC-vpravo. Uprav port, pokud je PC připojeno jinam.

ip verify source port-security

Zapne IP Source Guard s kontrolou zdrojové IP a MAC podle DHCP binding databáze a Port Security.

end

Ukončí konfiguraci.

show ip arp inspection vlan 1

Ověří stav DAI ve VLAN 1.

show ip verify source

Ověří IP Source Guard a bindingy na klientských portech.

Test statické nepovolené adresy

  1. Na PC-vpravo nastav na NIC2 statickou adresu 192.168.66.66/24 podle nastavení operačního systému.
  2. Z PC-vpravo pingni PC-vlevo a sleduj počítadla nebo logy switche.
  3. Porovnej zdrojovou IP/MAC s DHCP Snooping bindingem. IP Source Guard může provoz s adresou, kterou binding nepovoluje, zahodit.
show ip dhcp snooping binding

Ověří legitimní DHCP vazbu před testem statické adresy.

show ip arp inspection statistics

Zobrazí DAI statistiky a případné zahozené ARP pakety, pokud příkaz daná verze IOS podporuje.

show port-security interface FastEthernet 0/5

Ověří stav portu, naučenou MAC a případná porušení Port Security.

IP Source Guard závisí na DHCP Snooping bindingu. Pokud testovanému PC nastavíš statickou adresu, která v databázi není, očekávaný výsledek je blokace provozu; port se nemusí přepnout do err-disabled.

15. Obnovení původního stavu

Restartuj router, switch i počítače. Změněnou konfiguraci na Cisco zařízeních neukládej.

Router R1 a switch SW4

reload

Zadej samostatně v privilegovaném režimu routeru a poté switche. Na dotaz k uložení konfigurace odpověz no.

Neukládej změny: při dotazu „Save? [yes/no]“ zvol no. Potom restartuj oba počítače a vrať kabeláž do původního stavu.
